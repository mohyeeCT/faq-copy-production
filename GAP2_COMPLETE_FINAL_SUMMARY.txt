TECHNICAL ARCHITECTURE
================================================================================

DATA FLOW:

User selects in UI
        ↓
   app.py sidebar
        ↓
  st.session_state['selected_model']
        ↓
  Passed to generate_faq_batch()
        ↓
   copy_gen.py receives model parameter
        ↓
  Uses DEFAULT_MODELS if model=None
        ↓
  Uses specified model if model="name"
        ↓
  Provider function creates API call
        ↓
  FAQ generation with selected model
        ↓
  Results returned to user
