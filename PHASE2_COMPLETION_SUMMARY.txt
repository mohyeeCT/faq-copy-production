WHAT HAPPENS WHEN USER RUNS APP
================================================================================

Scenario 1: User doesn't interact with model dropdown
  1. App loads with default provider (Claude)
  2. Model dropdown shows "Default (claude-sonnet-4-6)"
  3. User never touches dropdown
  4. st.session_state['selected_model'] = None
  5. FAQ generation uses DEFAULT_MODELS["Claude"]
  6. Result: Same as before (backward compatible)

Scenario 2: User picks specific model
  1. User selects "Claude" from provider dropdown
  2. Model dropdown updates to show Claude options
  3. User picks "claude-sonnet-4-6" (not default)
  4. st.session_state['selected_model'] = "claude-sonnet-4-6"
  5. FAQ generation receives model="claude-sonnet-4-6"
  6. Backend uses specified model
  7. Result: FAQs generated with selected model

Scenario 3: User changes providers
  1. User selects "Claude" → models show Claude options
  2. User changes to "OpenAI" → models show OpenAI options
  3. Dropdown resets to "Default (gpt-5.5)"
  4. st.session_state['selected_model'] = None
  5. FAQ generation uses DEFAULT_MODELS["OpenAI"]
  6. Result: Correct model for new provider
